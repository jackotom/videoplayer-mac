Dual Engine

两种引擎，一种体验，没有打不开的文件。

常见格式走硬件解码，冷门格式自动落入 FFmpeg 软解。对使用者而言，切换完全无感——你只需要双击文件，其余交给播放器。

AVFoundation 硬解（默认）GPU 解码，省电、流畅，覆盖 MP4 / MOV / MKV / WebM 等常见格式。
FFmpeg 软解兜底DivX/Xvid AVI、FLV、WMV、FFV1、DTS 音轨等一切冷门格式，无死角。
自动回退（约 3ms）AVPlayer 解码失败瞬间切换到 FFmpeg 后端，几乎无感。
VideoToolbox GPU 加速软解后端同样支持硬件解码，4K 更流畅省电。

FAQ

常见问题

支持哪些视频格式？
几乎全部。默认使用 AVFoundation 硬件解码，覆盖 MP4 / MOV / MKV / WebM 等常见格式；遇到无法解码的冷门格式（DivX/Xvid AVI、FLV、WMV、FFV1、DTS 音轨等）会自动切换 FFmpeg 软解，也可以按 ⌥⌘R 手动切换。
系统要求是什么？
Apple Silicon（M 系列芯片）Mac，macOS 12 或更高版本。应用零外部依赖，无需安装 FFmpeg 等任何组件。
收费吗？
完全免费、开源（MIT 协议）。代码托管在 GitHub，欢迎提 Issue 与 PR。
安装时提示「无法打开，因为无法验证开发者」怎么办？
本应用使用 Apple Developer ID 签名并经过 Apple 公证，正常情况下双击即可安装。若仍被拦截，右键点击安装包 → 「打开」，确认一次即可。
如何让字幕、音轨选择自动记住？
播放器会按文件记忆你选择的音轨、内嵌字幕轨，以及是否关闭字幕。再次打开同一文件时自动恢复。
会自动更新吗？
会。应用内置 Sparkle 自动更新，启动时静默检查新版本并提示安装；也可以在应用菜单中点「检查更新…」手动检查。
支持画中画和投屏吗？
支持画中画（macOS 12+，硬解模式），控制条上也有隔空播放（AirPlay）输出路由按钮。
